A defined operating scope

Known limitations

Guardian G1.1 Pilot has a clearly defined operating scope. Not every data layout and environment has been verified yet.

01

Splitting by column

Guardian splits data by values in a selected column. Splitting by row is not supported.

02

Detail data and summaries

Layouts that combine detail data with summaries or aggregates are outside the Pilot’s verified scope.

03

Formulas in the split area

The behavior of formulas within the split area has not yet been sufficiently verified.

04

Your environment

Organizational policies, Office security settings, and system differences can affect Guardian installation or operation.

About ExcelForge

ExcelForge develops practical tools for working with Excel. We focus on solutions that make work easier, reduce unnecessary friction, and give users more control over the operations they perform.

We publish capabilities when they are sufficiently developed, tested, and well understood. If we cannot yet verify something reliably, we treat it as an area that needs further investigation, not as a finished product capability.

ExcelForge develops through real use and test results, not assumptions alone.
