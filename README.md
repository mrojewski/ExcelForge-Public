# ExcelForge Public

Public-facing repository for the ExcelForge project.

## Purpose

This repository contains material intended for publication outside the internal project workspace, including the public website, pilot-facing materials and reusable public media assets.

## Boundary of authority

`ExcelForge-Public` does **not** define product behaviour, architecture, governance, validation status or the canonical project state.

Public information published here must remain consistent with the approved state of the canonical ExcelForge project and its supporting evidence.

Canonical project repositories:
- `mrojewski/ExcelForge` — product and controlled project state;
- `mrojewski/ExcelForge-Evidence` — evidence, testing and development traceability.

## Public communication rule

A desired capability is not a product capability until it is implemented and sufficiently validated.

Public communication should distinguish clearly between:
- capabilities that are available now and supported by evidence;
- known limitations;
- areas currently under investigation;
- aspirations or desired capabilities that are not yet product facts.

Plans, intentions, hypotheses and desired future abilities must not be presented as current product capabilities.

## Current structure

- `docs/` — source for the public ExcelForge website and GitHub Pages publishing source;
- `docs/assets/` — website assets;
- `public/pilot/` — public materials for pilot users/testers;
- `public/media/` — reusable public media and communication assets.

## Distribution

ExcelForge Guardian G1.1 Pilot packages are distributed as verified assets of the canonical GitHub Release. The public site links directly to those Release assets; ZIP files are not duplicated in this repository.
